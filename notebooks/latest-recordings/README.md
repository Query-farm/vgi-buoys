# Recorded NOAA directory and latest reports

These are unchanged official response bytes captured for the latest-report freshness notebook. The manifest records each URL, UTC retrieval time, content type, byte count and SHA-256. The two requests are independent snapshots. Original observation timestamps remain unchanged; replay fetched_at is the local execution time. These files do not replace the older recordings used in the wave-exceedance notebook.

Source: NOAA National Data Buoy Center. Public observations are attributed to NOAA; use does not imply endorsement. Worker and branding licences remain separate.
